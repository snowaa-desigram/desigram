# desktop-shell Specification

## Purpose
Определяет поведение устанавливаемого десктоп-приложения: оно показывает тот же сайт, что и браузер, добавляя нативные возможности и не ослабляя безопасность.

## Requirements

### Requirement: Окно загружает сайт по URL
Приложение SHALL открывать главное окно с адресом продукта (`https://gram-designer.com`; переопределяется переменной `GRAM_DESIGNER_URL` для dev/stage). Размер и положение окна MUST сохраняться между запусками. Пока страница не загрузилась, окно MUST показывать нейтральный фон, а не белый экран.

#### Scenario: Первый запуск
- **WHEN** пользователь запускает приложение
- **THEN** открывается окно с сайтом, заголовок окна — заголовок страницы

#### Scenario: Нет сети
- **WHEN** сайт недоступен при старте
- **THEN** окно показывает экран «нет соединения» с кнопкой «Повторить», приложение не падает

### Requirement: Навигация ограничена своим origin
Переходы внутри окна MUST быть возможны только на origin сайта (и его поддомены `*.gram-designer.com`). Ссылки на внешние адреса и `window.open` SHALL открываться в системном браузере; загрузка сторонних страниц внутри окна MUST быть заблокирована.

#### Scenario: Внешняя ссылка
- **WHEN** пользователь кликает ссылку на `https://t.me/…`
- **THEN** она открывается в браузере по умолчанию, окно приложения остаётся на сайте

### Requirement: Безопасные настройки WebContents
Окно MUST создаваться с `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, `webSecurity: true`; единственный путь к нативному API — preload-мост (`desktop-bridge`).

#### Scenario: Проверка настроек
- **WHEN** запускается unit-тест конфигурации окна
- **THEN** все четыре флага имеют указанные значения

### Requirement: Deep-links
Приложение SHALL регистрировать схему `gram-designer://` и при открытии такой ссылки (в т.ч. когда приложение уже запущено — single instance) передавать её во фронт через мост, фокусируя окно.

#### Scenario: Ссылка при запущенном приложении
- **WHEN** ОС открывает `gram-designer://auth/callback?code=…`
- **THEN** второй экземпляр не создаётся, существующее окно получает фокус, фронт получает событие с этим URL

### Requirement: Автообновление
Приложение SHALL проверять обновления в GitHub Releases при старте и раз в час, скачивать в фоне и предлагать перезапуск; отказ откладывает установку до следующего запуска. В dev-режиме проверка MUST быть выключена.

#### Scenario: Есть новая версия
- **WHEN** в Releases опубликована версия новее установленной
- **THEN** после скачивания пользователь видит диалог «Обновление готово — перезапустить?»
